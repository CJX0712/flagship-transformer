## 一、核心结论（真实测量，非宣称）

### ① 短序列归纳：注意力碾压基线
任务：序列 `[c0..c7, c0]` → 预测 `c1`（d=48 / 3 层，2000 步）

| 模型 | loss | acc |
|------|------|-----|
| **注意力 Transformer** | **0.004** | **1.00** |
| 无注意力基线（平均池化 + 线性） | 2.295 | 0.20 |

### ② 长上下文（同分布）：训练即含长序列，注意力依然碾压
任务：训练 L∈[15,20]，测试 L∈{17,20}（d=64 / 4 层，10000 步）

| 测试长度 | 注意力 Transformer | 无注意力基线 | 结论 |
|---------|--------------------|--------------|------|
| L=17 | **acc 0.90** / loss 0.38 | acc 0.14 / loss 2.50 | ✅ 碾压 |
| L=20 | **acc 0.89** / loss 0.67 | acc 0.17 / loss 2.52 | ✅ 碾压 |

### ③ 长度外推：原生 RoPE 会崩塌（短板是尺子照出来的）
任务：训练仅 L∈[3,7]，测试**从未见过**的更长长度（d=64 / 4 层，6000 步，每长度 500 样本）

| 测试长度 | 原生 RoPE（plain） | 无注意力基线 | 结论 |
|---------|-------------------|--------------|------|
| L=8 | acc 0.74 | acc 0.15 | ✅ 还行 |
| L=12 | acc 0.48 | acc 0.16 | ⚠️ 优势明显衰减 |
| L=20 | acc 0.32 | acc 0.16 | ⚠️ 大幅衰减 |
| L=30 | acc 0.19 | acc 0.16 | ❌ 崩塌到基线水平 |

**结论**：原生 RoPE + 短序列训练，外推到 4 倍以上长度时会崩回基线水平。这不是 bug，是尺子测出来的真实边界。

### ④ 补洞成功：YaRN 在推理期免重训地把外推救回来
同一个**已经训练好**的模型（不重训），只在推理期切换 RoPE 缩放策略：

| 测试长度 | plain | NTK-aware | **YaRN** | 无注意力基线 |
|---------|-------|-----------|----------|--------------|
| L=8 | 0.74 | 0.75 | **0.76** | 0.15 |
| L=12 | 0.48 | 0.50 | **0.71** | 0.16 |
| L=20 | 0.32 | 0.35 | **0.60** | 0.16 |
| L=30 | 0.19 | 0.27 | **0.52** | 0.16 |

**结果**：YaRN 把 L=30 从 0.19（≈基线）拉到 **0.52**，L=20 从 0.32 拉到 **0.60**——外推短板被显著补上（`bench-extrap.js` 判定 `fixed = ✅`）。

两个诚实前提，必须一起说：
1. **YaRN 只在模型本身训够时才生效**。在 4000 步（模型尚弱）下，YaRN 只把 L=20 从 0.13 提到 0.26；训到 6000 步后才出现 0.60 / 0.52。位置编码缩放救不了欠训练的模型。
2. **NTK-aware 明显弱于 YaRN**（L=30: 0.27 vs 0.52）。真正起作用的是 YaRN 的 NTK-by-parts 分频段处理 + 注意力温度缩放，不是单纯缩放 base。

### ⑤ 长上下文预训练：把"补丁"升级为"训出来的能力"（深度实验）

任务：同样归纳任务，比较**两种训练分布**在外推到从未见过长度时的表现：
- **Regime A（旧补洞）**：只在 L∈[3,7] 短训 + 推理期 YaRN。
- **Regime B（⑤ 长上下文预训练）**：长度课程 `[3,7]→[8,13]→[14,20]`，即模型在训练中**真实见过**更长的位置区间，再做推理期 YaRN。

（d=48 / 3 层 / ffn=192，8000 步，最长训练长度 20，测试 L=30/40，单种子）

| 测试长度 | 短训+YaRN(A) | 长训原生(B·plain) | 长训+YaRN(B·yarn) | 结论 |
|---------|--------------|-------------------|-------------------|------|
| L=30 | **0.26** | 0.17 | 0.15 | ⚠️ 短训补丁仍占优 |
| L=40 | 0.19 | 0.16 | **0.39** | ✅ 长训+YaRN 超补丁 +0.20 |

**诚实解读（有尺子，不粉饰）：**
1. **"只靠训练更长上下文就能原生外推"这一朴素假设被证伪**。Regime B 不加 YaRN 的"原生"外推在 L=30/40 仍是 0.16–0.17，和短训原生（约 0.19）一样崩——训练分布拉长，并未让模型凭空学会原生外推。这是尺子照出的真实边界，不是失败，是认知。
2. **但"长训 + YaRN"在最难长度（L=40）真正超过了短训补丁**：0.39 vs 0.19（+0.20）。机理清晰——训练时见过 L≤20 的位置，让 L=21–40 经 YaRN 缩放的"拉伸距离"大幅缩短，YaRN 因此获得远超短训模型（只见过 L≤7）的发挥空间。**训练长度分布与位置编码缩放是互补的，不是替代的。**
3. 在较近的 L=30，短训补丁仍略占优（0.26 vs 0.15），说明课程调度在中等距离上尚未完全发挥，提示后续可优化课程平滑度。

**结论**：⑤ 没有"消灭"外推，但给出比"纯推理期补丁"更强的组合拳，并定位了清晰后续路线——更平滑/更长的长度课程 + 更大模型，把 L=40 的 0.39 继续往上推。

### ⑤·续：把长度课程拉到 L=40 —— 发现"外推是相对的"机制（主动修正 ⑤）

同一个归纳任务，但把课程**最长训练长度从 20 拉到 40**，并在更远的长度 L=30/40/50/60 上测（d=48/L3，8000 步）：

| 测试长度 | 短训原生 | 短训+YaRN | 长训原生(⑤·续) | 长训+YaRN | 长训原生 vs 短训原生 |
|---------|----------|-----------|----------------|-----------|----------------------|
| L=30 | 0.08 | 0.26 | **0.25** | **0.28** | 原生 +0.17 |
| L=40 | 0.06 | 0.19 | **0.32** | **0.32** | 原生 +0.26 |
| L=50 | 0.09 | 0.19 | **0.24** | **0.24** | 原生 +0.15 |
| L=60 | 0.10 | 0.17 | 0.15 | **0.24** | 原生 +0.05 |

（长训 = 课程 `[3,7]→[8,15]→[16,25]→[26,40]`，最长训练 40）

**诚实结论（含对 ⑤ 的主动修正）：**
1. **外推是"相对的"，不是绝对的**——原生外推能力取决于"测试长度离最长训练长度有多近"，而非绝对长度。把最长训练长度从 7（短训）拉到 40 后，**原生 RoPE 在 L=40（训练区间内）达到 0.32**，在 L=50（1.25×）仍有 0.24，全面碾压短训原生（0.06–0.10）。
2. **主动修正 ⑤ 的旧表述**：上次（课程到 20、测试 L=40 是 2× 距离）曾写下"长训原生不优于短训原生，朴素假设被证伪"。⑤·续 证明那句话**只在"2× 距离"下成立**——一旦课程逼近测试长度，原生外推就被显著修复（L=40 原生 +0.26、L=50 原生 +0.15）。正确结论是：**原生外推不是"训不出来"，而是"只在训练分布附近生效"**，这与真实 LLM 一致（训 4K 原生只稳到 4K，更远靠 YaRN / 延长训练）。
3. **补丁仍有存在价值**：在 L=60（1.5× 训练长度）原生回落到 0.15，靠 YaRN 拉回 0.24，仍优于短训补丁 0.17。即：长训分布 + YaRN 在最远长度仍是最稳组合。

**一句话**：⑤ 没"消灭"外推，但 ⑤·续 找到了它的真正机制——**外推能力随训练长度分布逼近测试长度而涌现**；补丁是"超出训练分布后"的保险，不是替代品。

## 二、十层架构分解（L1→L10）

| 层 | 名称 | 实现 |
|----|------|------|
| L1 | 数据/分词 | `genExampleInduction` / `genExampleInductionVar` |
| L2 | 张量/嵌入 | `embedding(ids, E)` |
| L3 | 位置编码 | **RoPE** 旋转位置编码（作用于 Q/K，注入相对位置） |
| L4 | 注意力 | 因果多头缩放点积 `multiHeadAttention` |
| L5 | 前馈 MLP | GeLU 扩张-收缩 `W1→GeLU→W2` |
| L6 | 残差/预归一化 | `x = x + f(rmsNorm(x))` |
| L7 | 层堆叠 | N 个预归一化块（长上下文实验用 4 层） |
| L8 | 输出头 | `matmul(xLast, Wlm) + blm` |
| L9 | 损失 | 数值稳定交叉熵 + 反向自动微分 |
| L10 | 评估/基准 | `runBenchmark` / `runGeneralizationBenchmark` |

## 六、认知反缴械声明

- 本库拒绝"看起来很完整"的幻觉：注意力是否真的有用，由**归纳任务的量化差距**裁决，而非宣称。
- 尺子的价值已经兑现过一次：早期用 KV 检索任务时，**注意力与基线打平（0.50 vs 0.55）**——因为该任务存在"键重复"泄漏捷径。没有基准，这个假优势会被当成真优势一直传下去。
- 这是**玩具规模的参考实现**：验证架构归纳偏置与训练闭环正确，**不宣称**在真实 LLM 基准（GPU 规模）上达到 SOTA。
- 短板与补洞都被记录在案：§1③ 记录原生 RoPE **外推崩塌**，§1④ 记录 **YaRN 把它救回**。同时写明两个前提——YaRN 只在模型训够时生效，且 NTK-aware 明显弱于 YaRN。
- 外推的机制已被尺子照清（§1⑤ + §1⑤·续，含主动修正）：原生 RoPE 外推**不是"训不出来"，而是"只在训练分布附近生效"**——课程最长训练长度拉到 40 后，原生在 L=40（训练区间内）达 **0.32**、L=50（1.25×）仍 0.24，碾压短训原生（0.06–0.10）。上一轮"朴素假设被证伪"那句话**只在 2× 距离下成立**，已诚实修正。YaRN 仍是"超出训练分布后"的必要保险（如 L=60 原生 0.15→YaRN 0.24）。下一步方向：更平滑/更长的长度课程 + 更大模型，把原生稳态区间从 ~1.25× 继续外推。
